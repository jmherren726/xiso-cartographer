# UI images

| File | What | Origin and licence |
|---|---|---|
| `background.png` | The panorama behind every screen, 1440 × 480 ([docs/ui-style.md](../../../docs/ui-style.md#the-background)) | Made by the project owner (jmherren726) and released with the project under its [MIT licence](../../../LICENSE), 2026-10-21. Scaled from the owner's 2000 × 667 original (Lanczos, Pillow 11.3.0). |

The XBE build converts each PNG here to a BMP in the XBE's `ui\` folder (`app/ui/ui-assets.mk`, `tools/ui/png2bmp.py`). Only 8-bit RGB or RGBA PNGs, not interlaced, are supported.

Never add game art, screenshots, or other people's logos or marks here (CLAUDE.md, [ui-style.md](../../../docs/ui-style.md#where-it-comes-from)).
